Create a small module of reusable Convex validators in `validators.ts`.

Start with this exported base validator and keep it unchanged:

```ts
import { v } from "convex/values";

export const profileValidator = v.object({
  name: v.string(),
  email: v.string(),
  internalNote: v.optional(v.string()),
});
```

Derive and export these four object validators from `profileValidator`:

1. `partialProfileValidator`: the same three fields, all optional.
2. `publicProfileValidator`: only the required `name` field.
3. `profileInputValidator`: all base fields except `internalNote`.
4. `identifiedProfileValidator`: all base fields plus a required string field
   named `externalId`.

Preserve the original field types and, except in the first transformation,
their original optionality. Do not add any other fields.

Use Convex's built-in object-validator composition API. Derive each result
from the base or another validator derived from it. Do not redeclare the
existing field validators or construct replacement object validators by hand.

Create only `validators.ts` and `package.json`, with `convex` pinned to
`1.44.0`. Keep all code in this one module and import only from
`convex/values`. No schema or backend functions are needed.
